# roadmap-lab

Small focused examples, plus a curated [roadmap.sh](https://roadmap.sh) checklist where every check links to code.

**Status:** bootstrapping. See [issue #1](https://github.com/hatsyio/roadmap-lab/issues/1).

## Contributing

- Tracker: GitHub Issues. Every change references an issue.
- Branches: `<type>/<issue>/<short-name>`, for example `feat/1/bootstrap`.
- Commits: [Conventional Commits](https://www.conventionalcommits.org/).
